# PaydMex

POS + CoDi payments + inventory + AI assistant for CDMX merchants — from street stalls to department stores. Built for the DevDay Exchange Community Hackathon CDMX on top of [pey](https://docs.pey.mx) (Banxico CoDi).

- `apps/api` — Node/TypeScript backend (pey integration, webhooks, AI)
- `apps/app` — Flutter app (Android, iOS, web)
- `apps/landing` — marketing site
- `docs/` — architecture and API contract
- `tasks/` — task briefs for coder agents

Setup: copy `.env.example` to `.env` and fill in values. See `docs/ARCHITECTURE.md`.
